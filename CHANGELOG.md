# Changelog

All notable changes to this project are listed here.

## Unreleased

### Fixed

- `firebase.json`: Hosting names its site (`before-you-tape-2026`, the project's default site). Without it the deploy tool failed with "resolving hosting target of a site with no site name or target name". Source: first live deploy from main. Verified: the deploy from a clean checkout of main succeeds and the live `version.json` reports the main SHA with `dirty` false; local CI mirror exit 0.

### Added

- `docs/evidence/lighthouse-live-2026-11-18/`: Lighthouse 13.6.0 reports (JSON and HTML) for the live site at `bf8e9f3`, desktop and mobile: Accessibility 100, Best Practices 100, SEO 91, Agentic Browsing 50. The misses come from `/robots.txt` and `/llms.txt`, which the single-page rewrite answered with `index.html`. Source: orchestrator Lighthouse run. Verified: the reports carry no key, local path or account detail; local CI mirror exit 0.
- `tests/e2e/a11y.spec.ts`: axe (WCAG 2.2 A and AA tags) on the home page at 1440 and 390 px; fails on any serious or critical violation and, with `BYT_EVIDENCE_DIR`, writes a summary per width. First run on the live site (`bf8e9f3`): 0 violations at both widths, in `docs/evidence/a11y-live-2026-11-18/`. Adds `@axe-core/playwright` 4.14.0, pinned (Mozilla Public License 2.0, dev only, listed in the README). Source: orchestrator tool audit. Verified: a throwaway control page with an image missing its alt text failed the same check with `image-alt`; local CI mirror exit 0.
- `evidence/appcheck-control/2026-11-18T08-33-01-194Z.json`: the App Check control run again after the first live deploy, with the live site as the referer: 401 "Firebase App Check token is invalid." without a token, then 200 with the debug token. The live `version.json` read `bf8e9f3`, `dirty` false, and the `live` Playwright project passed 2 of 2. Source: orchestrator (control and smoke test against the live URL). Verified: the evidence file holds neither the key nor the token; local CI mirror exit 0.
- `dist/version.json` now carries `dirty`: true when the tree had uncommitted or untracked changes at build time, so a deploy cannot claim a commit it does not match. The smoke test requires `dirty` to be false. Source: orchestrator (first live deploy must report the main SHA with dirty false). Verified: the smoke test failed on the missing field first; a build of an edited tree reads `dirty: true` and a build of the committed tree reads `false` and passes; local CI mirror exit 0.
- `docs/secrets-ledger.md`: every secret and control by name, place, state and date, with no values: the restricted browser key, the reCAPTCHA Enterprise key, both App Check debug tokens (Keychain items), the Gemini spend cap, App Check enforcement, the per-user AI limit, anonymous sign-in, the Firestore rules and the dependency audit. MFA on the Google and GitHub accounts stays PENDING until Stephen confirms it. Source: plan Task 5. Verified: each VERIFIED row was read back from its service on 2026-11-18; local CI mirror exit 0.
- `scripts/appcheck-control.ts` (`npm run appcheck:control`): proves App Check is enforced on Firebase AI Logic. A raw `generateContent` call with no App Check token must be refused with 401 before the script makes one with a debug token, which must return 200. It writes only status codes and reasons to `evidence/appcheck-control/`, redacts the key and tokens, and exits 1 unless it saw 401 then 200. Locally it reads `.env.local` through Node's `--env-file-if-exists`; the debug token comes from the environment. First result: `evidence/appcheck-control/2026-11-18T08-23-23-453Z.json` (401 "Firebase App Check token is invalid.", then 200 from gemini-3.5-flash-lite), run 15 minutes after enforcement. Source: plan Task 5. Verified: `scripts/appcheck-control.test.ts` failed before the module existed and passes; the evidence file was checked to hold neither the key nor the token; local CI mirror exit 0.
- Playwright smoke tests (`playwright.config.ts`, `tests/e2e/`): a `local` project against `vite preview` and a `live` project against `https://before-you-tape-2026.web.app` (`BYT_LIVE=1`). The site must serve `version.json` with the expected commit and load the home page. A fixture hands App Check its debug token before the app loads; in CI a missing `APPCHECK_DEBUG_TOKEN_CI` throws instead of skipping. Adds `@playwright/test` 1.64.1, pinned. Source: plan Task 5. Verified: both tests pass on the `local` project; with `CI=1` and no token the run exits 1 with "APPCHECK_DEBUG_TOKEN_CI is not set in CI"; local CI mirror exit 0.
- `src/firebase/app.ts`: `initFirebase(env)` refuses a missing config value by name, starts App Check with the reCAPTCHA Enterprise key before Auth, Firestore or AI Logic can be called, and connects the emulators when `VITE_USE_EMULATORS` is "true". `getAi(useLimitedUseTokens)` builds one Firebase AI Logic instance on the Gemini Developer API and refuses a different token setting later, which the SDK would reject anyway. `ensureSignedIn(auth)` waits for a saved session before signing in anonymously, so a reload keeps the same user. Adds `firebase` 13.4.0, pinned. Source: plan Task 5. Verified by `src/firebase/app.test.ts` (7 tests), which failed before the module existed; local CI mirror exit 0.
- Firebase project config for `before-you-tape-2026`: `firebase.json` (Hosting serves `dist` as a single-page app, Firestore in `nam5`, anonymous sign-in), `.firebaserc`, `firestore.rules` (deny all reads and writes until the app's own rules land) and an empty `firestore.indexes.json`. Source: plan Task 5. Verified: the rules and the auth config were deployed and read back (deployed rules match the file; anonymous sign-in reads enabled); local CI mirror exit 0.
- Web app shell: Vite, React and strict TypeScript, with the routes `/`, `/judge`, `/measured`, `/rules`, `/ran`, `/about`, `/worksheet` and `/blind/:token`. The `/desk/listing` and `/desk/eval` routes exist in development builds only. Verified by `src/App.test.tsx`.
- `dist/version.json` with the commit SHA and build time, written at build.
- `scripts/tone-check.ts`: fails on long dashes and curly quotes in user-facing text, and fails when it walks fewer files than its floor. Verified by `scripts/tone-check.test.ts`.
- `scripts/model-guard.ts`: fails on banned browser AI APIs and model libraries, on `availability(` outside `src/ai/gate.ts`, and on `getGenerativeModel` outside `src/ai/firebaseModels.ts`, with a floor on files walked. Verified by `scripts/model-guard.test.ts`.
- CI on GitHub Actions (`ubuntu-24.04`): lint, type check, tests, build, tone check, model guard, gitleaks over full history, and a check that no commit message carries a co-author trailer.
- Apache-2.0 `LICENSE` and `NOTICE`.
- `src/shared/itemRead.ts`: the item-read contract, 16 required fields and 37 categories from one field table, which also builds the strict JSON Schema and the parser. The parser rejects non-JSON, missing or extra fields, wrong types, unknown enum values and negative numbers, names the bad field, and clips label text to 160 characters. Verified by `src/shared/itemRead.test.ts`.
